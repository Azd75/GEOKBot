# GEOKBot# GEOKBot 🚀

Live Telegram bot for real-time prices of **BTC, ETH, SOL, AVAX**.

## Features
- Live prices from CoinGecko
- Commands: `/start`, `/price`, `/all`, `/btc`, `/eth`, `/sol`, `/avax`
- Clean formatted output with 24h change

## Setup

### 1. Create the bot
- Open [@BotFather](https://t.me/BotFather)
- Send `/newbot` and get your token

### 2. Local testing
```bash
git clone https://github.com/Azd75/GEOKBot.git
cd GEOKBot
pip install -r requirements.txt
